📥 Отправить в каталог

После одобрения модератором твой уровень появится в каталоге. Все игроки смогут его раскрасить.

Вход для автора

Экспорт уровня доступен только автору игры. Введите PIN.

⚙️ Экспорт уровня (автор)

JSON — для вставки в levels.js. PNG — для отправки/бэкапа.

💡 Обычные игроки видят только «📥 Отправить». Экспорт — для тебя.

Импорт уровня

Выберите способ: из картинки, из нашего PNG, из JSON.

🖼 Из картинки (нейросеть / фото)

Загрузите PNG/JPG — он превратится в уровень. Настройте параметры и импортируйте.

⚠️ Картинка большая, а сетка маленькая. Мелкие детали (глаза, блики) могут потеряться. Попробуйте размер 32×32 или больше.
